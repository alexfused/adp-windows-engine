# Third-party licences

This repository publishes two Windows engines for ADP Monitor. Each is made of third-party software; this file lists every component, its version and licence, and where its full licence texts and source are. The licence texts are in [licenses/](licenses/) (index: [licenses/INDEX.tsv](licenses/INDEX.tsv)). Each release also carries one file per engine, `<engine>.THIRD-PARTY-LICENSES.md`, with every text for that engine reproduced in full; ADP Monitor shows that file with the engine.

## Apple silicon engine, engine-arm64-11.18-2

Wine 11.18 development snapshot (arm64 host, ARM64EC, i386 WoW64) built from source with 30 of Hadron's Wine patches, plus FEX (x86 and x86-64 emulation inside Wine) with Hadron's 5 FEX patches, plus FreeType, libpng and GnuTLS with Nettle, GMP, libtasn1, libidn2 and libunistring, each built from its release tarball.

Release: https://github.com/alexfused/adp-windows-engine/releases/tag/engines-2026-10-21b

### Modifications

Wine and FEX are modified: Hadron's patches listed in patches.conf were applied (git am) to the upstream commits named below, and the result was built on 21 October 2026 with the scripts in adp-engine-arm64-11.18-2-build.tar.xz. The libraries in lib/ext were built from their upstream tarballs by build-ext.sh, with GnuTLS's upstream commit 29c2027c applied; their install names were then rewritten to @loader_path, local symbols stripped, and every Mach-O file signed with Alex Parkin's Developer ID under the engine's own identifier com.alexparkin.adpmonitor.winehost.

## Intel engine, engine-x86_64-11.18-1

Wine 11.18 development snapshot (x86_64 host, i386 and x86_64 Windows code through WoW64) built from source with 16 of Hadron's Wine patches and 3 of ours, plus FreeType and GnuTLS with Nettle, GMP and libtasn1, each built from its release tarball. Cross-compiled on an Apple silicon Mac for macOS 12.3 or later.

Release: https://github.com/alexfused/adp-windows-engine/releases/tag/engines-2026-10-21b

### Modifications

Wine is modified: 16 of Hadron's patches (patches.conf) and our 3 patches (patches/) were applied (patch -F0) to the upstream commit named below, and the result was built on 21 October 2026 with the scripts in adp-engine-x86_64-11.18-1-build.tar.xz. The libraries in lib/ext were cross-compiled from their upstream tarballs by build-deps.sh, with GnuTLS's upstream commit 29c2027c applied; their install names were then rewritten to @loader_path, local symbols stripped, and every Mach-O file signed with Alex Parkin's Developer ID under the engine's own identifier com.alexparkin.adpmonitor.winehost.
